# ledger-country-do-testing (dev-only)

Never installed in an image. A fake DGII (`ledger-fake-dgii`, written from DGII's *Descripción Técnica*), test
subjects named as Dominican authorities name them (on `ledger_testing.pki`), xmlsec1 as the reference
signature verifier, and samples. The spike's CLI is retired: the stack itself runs against TesteCF
(`docs/runbooks/do/testecf.md`).
